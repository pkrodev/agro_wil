# AgroWil – strona i sklep

Strona firmowa AgroWil (części John Deere, nawigacje FJDynamics, węże hydrauliczne, koszenie kukurydzy) ze sklepem internetowym.
Hostowana na GitHub Pages: https://pkrodev.github.io/agro_wil/

- `index.html` – strona główna (sklep + informacje o usługach), `agrowilfjdynamics.html` – nawigacje FJDynamics
- `sklep.html`, `produkt.html`, `koszyk.html`, `zamowienie.html` – sklep
- `shop/products.js` – katalog (opisy, specyfikacje, rekomendacje), `shop/photos.js` – zdjęcia produktów
- `shop/shopify-config.js` – połączenie z Shopify (kasa i płatności) – instrukcja w [SHOPIFY.md](SHOPIFY.md)
